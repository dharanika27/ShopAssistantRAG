## Description
Bootstrap the FastAPI application with CORS for the Streamlit frontend, a health endpoint, request logging, and global exception handling that maps internal/service errors to the BRD user-facing messages — never leaking stack traces.

## Acceptance Criteria
1. `GET /api/health` returns 200 with a JSON status body.
2. CORS is configured to allow requests from the Streamlit frontend origin.
3. An unhandled exception in any route returns a structured JSON error with an appropriate HTTP status and no stack trace in the response body.
4. Service-layer typed errors (Gemini/Pinecone/MySQL) are mapped to their respective BRD user messages.
5. Each request is logged with method, path, and status (no secrets in logs).
