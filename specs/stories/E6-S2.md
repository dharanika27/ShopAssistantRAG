## Description
Assemble the retrieved (hydrated) products into a prompt context and use Gemini `gemini-1.5-flash` to produce a natural-language response strictly grounded in those products — no invented products, prices, or attributes (BRD grounding requirement and risk mitigation).

## Acceptance Criteria
1. The generation prompt includes only the retrieved product records as context (name, brand, category, price, etc.).
2. The generated answer references only products present in the supplied context — no product not in context appears in the response.
3. When the context is empty, generation produces a friendly no-match message and suggests available categories rather than inventing products.
4. The generation call uses model `gemini-1.5-flash` from centralized settings.
5. A Gemini generation failure returns the BRD user-facing message ("The AI assistant is temporarily unavailable…") rather than an exception/stack trace.
