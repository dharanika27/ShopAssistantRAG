## Description
Provide a reusable structured logger used across retrieval operations, API requests, and embedding generation. Logs must never contain secrets and must support correlation of a single request/session.

## Acceptance Criteria
1. A `get_logger(name)` helper returns a configured logger emitting structured records with timestamp, level, logger name, and message.
2. Log records support an optional `session_id` / `request_id` context field for correlation.
3. Log level is configurable via environment variable (default `INFO`).
4. No log statement in the codebase emits `GOOGLE_API_KEY` or `PINECONE_API_KEY` values (verified by inspection/test).
