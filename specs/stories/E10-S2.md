## Description
Provide the bootstrap glue and documentation needed to run the demo from a clean checkout: schema init on first boot, an init/bootstrap script, and README run instructions for both dev mode and Docker mode.

## Acceptance Criteria
1. On first startup the MySQL schema (E2-S1) is initialized automatically (compose init or entrypoint).
2. An `init.sh` (or equivalent) bootstraps the environment: copies `.env.example` to `.env` if absent and runs the ingestion script.
3. README documents both run paths: dev mode (uvicorn + streamlit + local MySQL) and Docker mode (`docker-compose up`).
4. Following the README from a clean checkout yields a working app reachable in the browser.
