## Description
Integration tests against the FastAPI endpoints and an E2E test of the core user journey (browse → query → refine → no-match) to satisfy the BRD Definition of Done items 12–14.

## Acceptance Criteria
1. An integration test calls `POST /api/chat` and asserts a 200 with a reply and ≤5 products against a seeded test catalog.
2. An integration test calls `GET /api/products` with filters and asserts correct filtered results.
3. A multi-turn integration test confirms session refinement ("only red ones") changes results within one session.
4. A no-match integration test confirms a graceful no-match response with zero products.
5. The core user journey completes with no blocking errors (BRD DoD item 14).
