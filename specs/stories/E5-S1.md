## Description
Translate a natural-language query into a structured `QueryFilters` object using Gemini structured JSON output. A validation/normalization layer maps synonyms onto canonical enums (e.g., Crimson→Red, Trainers→Shoes) and discards values outside the catalog vocabulary, addressing BRD risk R-2.

## Acceptance Criteria
1. "Show me red Nike shoes under ₹3000" yields `{brand: Nike, color: Red, category: Shoes, max_price: 3000}`.
2. A color synonym such as "Crimson" normalizes to `Red`; a category synonym such as "Trainers" normalizes to `Shoes`.
3. An extracted value that matches no known enum is dropped (set to `None`) rather than passed downstream.
4. A price-only query ("under ₹500") yields `max_price: 500` with all other filters `None`.
5. Malformed or non-JSON model output is handled gracefully and yields an empty `QueryFilters` (all `None`) rather than crashing.
