## Description
Execute the BRD hybrid retrieval strategy: apply structured metadata pre-filters to Pinecone, run semantic vector search on the residual query intent, and return the top-5 ranked product IDs. Orchestrated via LangChain.

## Acceptance Criteria
1. `retrieve(query, filters)` applies `brand`, `color`, `category`, `gender` as Pinecone metadata equality filters.
2. `min_price` / `max_price` are applied as Pinecone numeric range filters on the `price` metadata.
3. Semantic search uses the 768-dim embedding of the query intent and returns results ordered by similarity score.
4. At most 5 product IDs are returned per call.
5. When metadata filters exclude all vectors, the retriever returns an empty list (enabling the no-match path) without error.
