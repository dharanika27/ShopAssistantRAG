## Description
The primary feature UI: a Streamlit chat interface where the shopper asks natural-language questions, sees the grounded NL reply, and views up to 5 recommended product cards inline — with multi-turn refinement preserved across the session.

## Acceptance Criteria
1. A chat input lets the user submit a natural-language query and displays the assistant's NL reply.
2. Up to 5 recommended product cards render inline with the assistant reply.
3. A stable `session_id` is generated per browser session and sent on every `POST /api/chat` call.
4. Multi-turn refinement works: a follow-up like "only red ones" updates results within the same session.
5. A no-match query shows the friendly no-match message and zero product cards.
6. Conversation history (previous turns) remains visible in the chat transcript during the session.
