## Description
Upsert product embeddings into Pinecone with the retrieval metadata needed for hybrid search (brand, color, category, gender, price). The vector ID is the product ID so retrieval results map directly back to MySQL records.

## Acceptance Criteria
1. `upsert_products(products, vectors)` writes one vector per product, keyed by `product_id`.
2. Each vector carries metadata fields: `brand`, `color`, `category`, `gender`, `price`.
3. Upserting a product ID that already exists overwrites the prior vector and metadata (no duplicates).
4. `price` metadata is stored as a numeric type so range filters (`$lte` / `$gte`) work.
5. Upsert is batched so 500–1000 products can be loaded in a single ingestion run without exceeding request limits.
