## Description
Initialize the Pinecone client and ensure the target index exists with the correct dimension (768) and similarity metric, matching the Gemini embedding output. Provides a reusable handle used by upsert and query operations.

## Acceptance Criteria
1. On startup, the client connects to Pinecone using `PINECONE_API_KEY` from centralized settings.
2. If the configured index does not exist, it is created with dimension 768 and cosine metric; if it already exists, it is reused (no error).
3. Attempting to create an index with a dimension other than 768 is rejected/flagged as a configuration mismatch.
4. A Pinecone connection failure raises a typed retrieval error mappable to the BRD user message.
