## Description
Containerize the stack so the whole app runs via `docker-compose up` (BRD DoD item 11). FastAPI, Streamlit, and MySQL run as containers; Gemini and Pinecone remain external cloud services.

## Acceptance Criteria
1. A Dockerfile builds the FastAPI backend image; a Dockerfile builds the Streamlit frontend image.
2. `docker-compose.yml` defines `backend`, `frontend`, and `mysql` services on a shared network.
3. `docker-compose up` brings the stack online and the Streamlit UI can reach the backend, which reaches MySQL.
4. MySQL data persists across container restarts via a named volume.
5. Secrets (Google/Pinecone keys, DB creds) are injected via environment/`.env`, never baked into images.
