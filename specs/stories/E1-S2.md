## Description
Provide a single typed settings object that loads all secrets and connection parameters from a `.env` file. No secret may be hardcoded or committed. This is consumed by the embedding client, Pinecone client, MySQL repository, and the FastAPI app.

## Acceptance Criteria
1. Settings load `GOOGLE_API_KEY`, `PINECONE_API_KEY`, `MYSQL_HOST`, `MYSQL_PORT`, `MYSQL_USER`, `MYSQL_PASSWORD`, `MYSQL_DATABASE` from environment / `.env`.
2. A `.env.example` file lists every required key with placeholder (non-secret) values.
3. `.env` is listed in `.gitignore`.
4. Loading settings with a required key absent raises a clear error naming the missing key.
5. Settings expose typed defaults for `PINECONE_INDEX_NAME`, `EMBEDDING_MODEL` (`text-embedding-004`), `GENERATION_MODEL` (`gemini-1.5-flash`), and `EMBEDDING_DIM` (768).
