## Description
Serve the product catalog grid and the traditional filter controls from MySQL (source of truth). Supports listing products and applying structured UI filters (brand, category, gender, price range, color).

## Acceptance Criteria
1. `GET /api/products` returns the catalog as a list of product objects with image, name, brand, category, price, and stock status.
2. `GET /api/products` accepts query params for `brand`, `category`, `gender`, `color`, `min_price`, `max_price` and returns only matching products.
3. `GET /api/filters` returns the available filter option values (distinct brands, categories, genders, colors) for populating UI controls.
4. Filtering by a value with no matches returns an empty list with HTTP 200 (not an error).
5. Each returned product reflects correct stock status (`stock=0` surfaced as out of stock).
