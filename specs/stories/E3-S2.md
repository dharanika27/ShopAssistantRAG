## Description
Wrap the Google Gemini `text-embedding-004` model to produce 768-dimensional vectors for product texts (ingestion) and query texts (retrieval). Provides a single integration point so embedding behavior can be mocked in tests.

## Acceptance Criteria
1. `embed_text(text)` returns a vector of exactly 768 floats using model `text-embedding-004`.
2. `embed_batch([t1, t2, ...])` returns one 768-dim vector per input text, in order.
3. A Gemini API error is caught and re-raised as a typed embedding error (no raw SDK exception leaks to callers).
4. The client reads `GOOGLE_API_KEY` and the embedding model name from centralized settings (E1-S2), not hardcoded values.
5. The client is mockable: tests can substitute embedding output without calling the live API.
