## Description
Provide Streamlit UI controls to filter the catalog grid by Brand, Category, Gender, Price Range, and Color, populated from the filter-options endpoint and driving the products endpoint.

## Acceptance Criteria
1. Filter controls for Brand, Category, Gender, Color, and a Price Range slider are rendered, populated from `GET /api/filters`.
2. Selecting a filter re-queries `GET /api/products` with the chosen params and updates the grid.
3. Combining multiple filters (e.g., Brand=Nike + Category=Shoes) returns only products matching all selected criteria.
4. Clearing filters restores the full catalog grid.
