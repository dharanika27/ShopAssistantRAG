## Description
Pinecone returns only IDs and metadata; full display records (description, image URL, stock, etc.) live in MySQL. This step hydrates the top-5 retrieved IDs into complete `Product` objects, preserving retrieval rank order.

## Acceptance Criteria
1. Given a ranked list of product IDs from the retriever, hydration returns full `Product` objects for those IDs.
2. The output preserves the retrieval ranking order (rank 1 first).
3. An ID present in Pinecone but absent from MySQL is skipped and logged, without failing the whole request.
4. An empty ID list returns an empty product list (no MySQL query issued).
