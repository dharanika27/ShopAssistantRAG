## Description
Provide the data-access layer over MySQL. Supports upserting products during ingestion, listing/filtering products for the catalog grid, and bulk-fetching full product records by a list of IDs returned from Pinecone retrieval.

## Acceptance Criteria
1. `upsert_product(product)` inserts a new row and updates an existing row when `product_id` already exists.
2. `get_products_by_ids([id1, id2, ...])` returns the full `Product` records for those IDs, preserving the input ordering.
3. `list_products(filters)` returns products matching brand/category/gender/color/price-range filters; passing no filters returns all products.
4. `get_products_by_ids` with an empty list returns an empty list without querying the database.
5. A MySQL connection failure raises a typed repository error (not a raw driver exception) so the service layer can map it to the user message.
