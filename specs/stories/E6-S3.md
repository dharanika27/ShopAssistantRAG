## Description
The end-to-end chat orchestration that ties filter extraction, accumulating session state, hybrid retrieval, hydration, and grounded generation together, plus the BRD context-reset rules and edge-case handling. This is the conversational core (risk R-1).

## Acceptance Criteria
1. A follow-up refinement ("only red ones") merges onto existing session filters and rebuilds a fresh hybrid retrieval (does not just filter the prior result list).
2. "Cheaper options" lowers the current upper price ceiling and re-runs retrieval for lower-priced alternatives.
3. A clear category change ("Now show me bags") or explicit "forget previous search" resets the accumulated filter state.
4. An empty result set produces a friendly no-match message with category suggestions and zero product cards.
5. Greetings/small talk and invalid queries ("asdfgh") return a scoped conversational/clarification response without crashing or retrieving products.
6. Each chat turn returns a natural-language message plus up to 5 grounded product cards.
