## Description
Read the product catalog CSV, validate each row against the domain model, and produce clean `Product` objects ready for MySQL upsert. Invalid rows are skipped (not fatal) and recorded for the ingestion summary.

## Acceptance Criteria
1. A valid CSV row with all required fields is parsed into a `Product` object.
2. A row missing `name`, `price`, or `category` is skipped and recorded as a validation failure with the row identifier and reason.
3. A row with `category` or `gender` outside the allowed enum values is skipped and recorded as a validation failure.
4. `tags` are parsed from a delimited string into a list of trimmed strings.
5. The loader returns both the list of valid products and a list of skipped-row failure records.
