## Description
Unit test the critical RAG path with Gemini, Pinecone, and MySQL mocked, per the BRD testing NFR. Covers filter extraction/normalization, hybrid retrieval, hydration ordering, and multi-turn reset rules.

## Acceptance Criteria
1. Filter-extraction tests assert enum normalization (Crimson→Red, Trainers→Shoes) and price-only extraction with all external calls mocked.
2. Hybrid-retrieval tests assert metadata filters + range filters are passed to a mocked Pinecone and at most 5 IDs returned.
3. Hydration tests assert retrieval rank order is preserved and missing IDs are skipped.
4. Multi-turn tests assert refinement accumulates filters and a category change resets state.
5. The test suite runs without any live Gemini/Pinecone/MySQL connection and passes green.
