## Description
Define MySQL as the system of record. Create the `products` table schema matching the BRD data model and provide an idempotent schema-initialization script so a fresh database can be bootstrapped for local dev and Docker.

## Acceptance Criteria
1. A `products` table exists with columns: `product_id` (PK), `name` (NOT NULL), `description`, `brand`, `category` (NOT NULL), `gender`, `color`, `price` DECIMAL(10,2) (NOT NULL), `image_url`, `stock` INT DEFAULT 0, `tags`.
2. `category` and `gender` are constrained to the BRD enum value sets (via CHECK or application-enforced).
3. Running the init script twice does not error and does not duplicate the table (idempotent `CREATE TABLE IF NOT EXISTS`).
4. `product_id` is the primary key and rejects duplicate inserts.
5. The schema script runs successfully against a clean MySQL 8 instance.
