## Description
Compose the single text string embedded per product from its semantic fields, per the BRD embedding strategy. Price, stock, and image URL are deliberately excluded from the embedding text (they remain Pinecone metadata).

## Acceptance Criteria
1. `build_embedding_text(product)` concatenates Name, Description, Brand, Category, Gender, Color, and Tags into one string.
2. The output string does NOT contain the product price, stock quantity, or image URL.
3. Missing optional fields (e.g., no color or no tags) are omitted gracefully without producing literal `None` text.
4. Given the BRD example product, the output reads as a coherent sentence-style description (e.g., includes "Nike", "running shoes", "men", "Shoes", and tags).
