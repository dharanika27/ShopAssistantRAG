## Description
The standalone ingestion script wiring the full data flow: CSV → validate → MySQL upsert → build embedding text → Gemini embeddings → Pinecone upsert. Per the BRD, embedding failures are non-fatal and every run prints a summary report.

## Acceptance Criteria
1. Running the script ingests a CSV end-to-end: valid rows land in MySQL and corresponding vectors land in Pinecone.
2. A row that fails CSV validation is skipped and counted as a failure (does not abort the run).
3. A product whose embedding generation fails is logged, skipped from Pinecone upsert, and included in the summary.
4. At completion the script prints a summary with total processed, successful, failed counts, and failure reasons.
5. Re-running the script on the same CSV updates existing records (upsert) rather than creating duplicates in MySQL or Pinecone.
